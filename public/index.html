재사용 스킬

Codex 표준 SKILL.md로 저장하고, 연결한 에이전트 작업에 적용합니다.

메인 AI가 작업마다 필요한 배정 스킬만 골라 불러옵니다.

스킬은 Agent Desk의 로컬 데이터 폴더에 SKILL.md 형식으로 저장되어 프로젝트를 바꾸어도 재사용됩니다. 관련 없는 작업에는 지침을 보내지 않아 토큰을 아낍니다. 권한이나 보호 규칙은 바꾸지 않으며, 한 에이전트에 활성 스킬은 최대 5개까지 연결할 수 있습니다.

실행과 사용량 설정

Supabase 연결 · 마이그레이션

현재 선택한 프로젝트에 대해 연결하고, 원격 DB 적용 전 변경 목록을 확인합니다.

상태 확인 중
비밀값은 이 PC의 Agent Desk 데이터 폴더에 Windows 계정 보안(DPAPI)으로 암호화해 저장합니다. 프로젝트 파일이나 브라우저 저장소에는 기록하지 않습니다.
Supabase CLIAgent Desk 전용 폴더에 설치합니다. 선택한 프로젝트의 package.json은 바꾸지 않습니다.
원격 마이그레이션프로젝트를 선택하면 로컬 SQL 파일을 찾습니다.

적용은 선택한 Supabase 데이터베이스의 스키마를 변경합니다. 미리보기는 로컬에서 아직 원격 이력이 확인되지 않은 모든 마이그레이션을 보여 줍니다. 대상 ref와 파일 목록을 꼭 확인한 뒤 적용하세요.

Codex에 연결된 나의 작업 공간

기존 Codex 로그인을 사용합니다. 이 대시보드에서 시작한 작업을 표시하며, Codex 앱의 다른 대화는 자동으로 가져오지 않습니다. AI 요청에는 인터넷이 필요합니다.
