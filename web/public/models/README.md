# RobotExpressive.glb

The robot in the dashboard's 3D office.

- Model by Tomás Laulhé (Quaternius style low-poly robot), CC0 1.0. Consider supporting the creator's Patreon.
- Modifications by Don McCurdy: three facial expression morph targets, converted with FBX2GLTF, duplicate materials removed.
- Taken from the three.js examples: `examples/models/gltf/RobotExpressive/RobotExpressive.glb`.

Animations used: Idle, Walking, Wave, ThumbsUp, Yes, No. Expressions used: Sad, Surprised.
