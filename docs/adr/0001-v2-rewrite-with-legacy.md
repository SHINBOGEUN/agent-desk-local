# ADR 0001 · v1을 legacy/로 동결하고 v2를 새로 설계한다

- 날짜: 2026-11-13
- 상태: 결정

## 배경
v1의 `lib/hub.mjs`(1,091줄)는 조율·Codex 프로토콜·승인·사용량 계산이 한 파일에 묶여 있어, Codex와 Claude를 함께 또는 하나만 쓰는 구조로 바꾸기 어렵다. 실측(요청 60건)에서 토큰 10.7배 과대 계상, 메인 맥락 비대화, 체커 첫 검증 PASS 0/23이 확인됐다.

## 결정
- 현재 코드를 `v1-legacy` 태그로 고정하고 같은 저장소의 `legacy/`로 옮긴다.
- v2는 TypeScript 모노레포(`packages/`)로 새로 작성하고, 대시보드도 새로 만든다.
- 보안(CSRF·Origin·CSP·비밀값 가리기), DPAPI, 5시간 한도 추적, 프로세스 관리, Supabase는 테스트와 함께 이식한다.

## 결과
같은 벤치마크(`bench/`)로 v1과 v2를 측정해 개선 효과를 수치로 비교한다.
