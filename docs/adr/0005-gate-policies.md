# ADR 0005: 게이트 판정 정책 세부 결정

- 날짜: 2026-11-13
- 상태: 결정 (사용자 선택)
- 범위: 로드맵 2-4(게이트 G2·G3·G5, REDO)

| 질문 | 결정 | 이유 |
|---|---|---|
| builder가 요구사항을 `unverified`로 보고했고 G3는 통과(또는 없음) | G3가 있고 통과하면 `completed`로 끝내고 '확인 못 한 항목'을 결과에 그대로 표시. verify 명령이 없으면 `needs_review` | v1 기준선의 거짓 경보(18/35)를 줄이되, 자동 검증 근거가 없을 때는 사용자에게 넘김 |
| G2에서 보고에 없는데 실제로 바뀐 파일 | 기본 무시 목록(`node_modules/`, `.git/`)과 프로젝트 설정의 `ignore`를 제외한 불일치는 REDO 사유. 보고에는 있는데 실제로 안 바뀐 파일도 REDO(사실과 다른 보고) | 설계서의 '보고한 변경 파일 = 실제 변경 파일' 유지. 산출물 파일이 문제되면 `ignore`로 해결 |
| G5 토큰 한도의 기준 | 총 토큰(`totalTokens` 합) | 기준선 보고서의 평균 토큰과 같은 기준이라 직접 비교 가능. 캐시 입력이 포함되어 값이 크므로 한도는 이를 감안해 설정 |

추가 구현 규칙(결정 아님, 설계서 기준 확인)
- 보호 경로는 `.agent-desk/`와 `.git`의 `HEAD`·`config`·`refs/`입니다. `.git/index`와 `objects/`는 `git status` 같은 읽기 명령에도 바뀌므로 대조하지 않습니다.
- REDO는 Run당 최대 2회. 첫 REDO는 같은 builder 세션, 두 번째는 실패 요약을 담은 새 세션입니다.
