# ADR 0006 · 복원 지점은 파일 복사로 시작한다

- 상태: 채택 (2026-11-13)
- 관련: design-v2.md "스냅샷과 되돌리기", 로드맵 2-11

## 결정
build 단계 직전에 프로젝트 파일(무시 목록·`node_modules/` 제외)을 데이터 폴더 `restore/<run id>/`에 복사합니다. `agent-desk revert <run id>`는 먼저 계획(복원할 파일, 삭제할 파일)만 보여 주고, `--yes`를 붙여야 적용합니다. 자동 되돌리기는 하지 않습니다.

## 이유
- 설계서는 "git이면 별도 참조, 아니면 파일 복사"였습니다. git 참조는 사용자의 저장소 상태(인덱스, 객체)를 건드릴 위험과 git 의존성이 있어, 어디서나 같은 동작을 하는 파일 복사 하나로 먼저 갑니다.
- 한도: 파일 5,000개·100 MB를 넘으면 복원 지점을 만들지 않고 `warnings`에 알립니다(Run은 계속). 최근 10개 Run만 보관합니다.

## 한계와 이후
- `.git/`과 `.agent-desk/`는 복원하지 않습니다(보호 경로는 G2가 따로 지킵니다).
- 같은 프로젝트에서 이후 Run이 있었다면 그 변경도 함께 되돌려진다고 알립니다.
- 큰 저장소를 위한 git 기반 방식은 필요가 확인되면 추가합니다.
