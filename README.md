# Agent Desk Local

현재 PC에서 메인 AI에게 요청하고, 에이전트의 배정·작업·대기 상태와 보고를 확인하는 로컬 대시보드입니다.

## 시작

1. Windows PC에 Node.js 22 이상과 Codex CLI를 설치합니다. `codex login`으로 본인 계정에 로그인하고 `codex login status`로 확인합니다.
2. `Start-AgentDesk.cmd`를 더블클릭합니다.
3. `http://127.0.0.1:4317`에서 사용합니다. 로컬 서버는 숨겨진 창으로 실행됩니다.

터미널에서는 이 폴더에서 `npm start`로 실행할 수 있습니다. 별도 패키지 설치가 필요하지 않습니다. 시작 스크립트로 실행한 서버는 `powershell -File .\Stop-AgentDesk.ps1`로 종료합니다.

## 사용

- 프로젝트 폴더를 연결하고 메인 AI에게 요청합니다. 첫 프로젝트는 상위 AI_Agent 폴더이며 기본 권한은 읽기 전용입니다.
- 대화 입력창의 **요청 정리 AI 거치기** 스위치는 기본적으로 꺼져 있습니다. 끄면 원문을 바로 메인 AI에 전달합니다. 켜면 읽기 전용 프롬프트 정리 AI(GPT-6 Luna · Low)가 원문을 짧게 정리한 뒤 원문과 정리본을 함께 전달합니다. 원문이 우선이며 새 요구나 권한을 추가하지 않도록 지시합니다. 정리에 실패하면 원문으로 계속 진행합니다. 정리 단계에도 토큰이 사용되며 결과와 사용량은 작업 기록에 남습니다.
- 파일을 만들거나 수정하려면 프로젝트 설정에서 **실행 담당 에이전트의 파일 수정 허용**을 선택합니다. 에이전트에도 파일 수정 권한이 있어야 합니다.
- 메인 AI가 `agent_desk_run` 도구로 등록된 에이전트에게 작업을 맡깁니다. 단순 대화는 직접 처리합니다. 위임을 확인하려면 “리서처에게 조사시키고 체커에게 검증시켜 줘”처럼 요청합니다.
- 후속 작업에 선행 결과가 필요하면 메인 AI가 완료된 팀원 작업의 ID를 지정해 보고를 인계합니다. 같은 요청에서 완료된 보고만 최대 3개, 각 1,800자까지 전달하고 작업 기록에 인계 출처를 남깁니다. 진행 중에는 흐름도에 팀원 간 인계선이 표시됩니다.
- 에이전트 메뉴에서 역할, 모델, 추론 수준, 지침, 활성화 여부를 설정하고 팀원을 추가할 수 있습니다. 메인 AI는 GPT-6 Sol · High, 새 팀원은 GPT-6 Luna · High로 시작하며 모델 이름과 슬라이더를 눌러 각각 변경할 수 있습니다.
- **AI 모니터링 에이전트**는 에이전트 메뉴의 ‘운영 점검 요청’을 눌러 메인 AI에게 요청할 때 실행됩니다. 같은 프로젝트의 최근 요청 최대 8건에 대한 위임, 상태, 토큰, 검증 결과와 현재 팀 지침을 축약해 확인합니다. 근거가 있는 개선안만 최대 3개까지 메인 AI가 `agent_desk_update_guidance` 도구로 저장하며, 개선이 없으면 지침을 바꾸지 않습니다. 평소 요청마다 모니터를 호출하지 않아 추가 AI 사용량을 피합니다.
- ‘운영 점검 요청’은 대시보드의 통계 아래에서도 누를 수 있습니다. 버튼은 요청 문구만 입력하며 전송 버튼을 눌러야 실행됩니다.
- 모니터가 제안한 짧은 운영 지침은 에이전트의 기본 작업 지침과 별도 필드에 저장됩니다. 에이전트 설정에서 읽고, 고치거나 비울 수 있습니다. 저장된 지침은 다음 작업부터 적용되며 기존 운영 지침을 계속 덧붙이지 않고 교체합니다.
- 작업 상세에서 팀원별 보고, 실행 명령, 검증 결과와 실패를 확인합니다. 실시간 활동에는 실제 Codex 이벤트만 표시합니다.
- 작업 상세에는 `요청 분석 → 팀 작업 → 검증 → 최종 보고` 흐름이 표시됩니다. 파일 수정 권한을 실제 사용한 요청은 마지막 변경 이후 체커의 `[검증 결과: PASS]` 보고가 있어야 완료로 표시됩니다. 검증이 빠졌거나 실패하면 `검토 필요`로 남습니다.
- Codex가 실행 확인이나 질문을 보내면 대화창 안에 표시합니다. 지원하지 않는 외부 앱의 확인 양식은 거절합니다.
- 환경 설정에서 동시 실행 수, 위임 횟수, 실행 시간과 토큰 예산을 조절합니다.

## 범위와 저장

이 대시보드에서 시작한 작업을 관리합니다. 기존 Codex 앱 대화나 다른 프로그램의 에이전트 상태를 자동으로 가져오지는 않습니다. 브라우저를 닫아도 서버가 켜져 있으면 진행 중인 작업은 계속됩니다. PC 종료·서버 재시작 때 중단된 작업은 중단 상태로 복구되며 자동 재실행하지 않습니다.

현재 실행과 검증은 Windows에서만 완료했습니다. macOS·Linux는 Node 서버와 Codex CLI를 이용할 수 있는 구조지만, 시작·종료 스크립트와 파일 작업을 해당 운영체제에서 검증해야 합니다. 별도의 설치 프로그램이나 다중 사용자 로그인은 아직 없습니다.

화면과 작업 기록은 로컬에서 운영되며 AI 추론에는 인터넷과 현재 Codex 계정의 사용량이 필요합니다. 기존 Codex 인증을 CLI가 관리하며 이 앱은 로그인 토큰을 복사하거나 웹에 노출하지 않습니다. 이 버전은 개인 PC에서 사용하는 로컬 앱입니다.

`data/state.json`에 프로젝트별 대화·작업 기록(최근 60개), 품질 확인 판정, 에이전트 지침·모델·추론 수준 등 설정을 저장합니다. 각 요청의 메인 AI에는 동일 프로젝트의 최근 완료 대화 3개를 최대 6,000자로 전달합니다. 팀원에게는 해당 작업 지시와 메인 AI가 지정한 선행 보고만 전달합니다. 장기 기억이나 모든 대화의 완전한 기억을 제공하지 않습니다. Codex 로그인 토큰은 이 파일에 저장하지 않지만, 지침이나 작업 요청에 민감한 내용을 직접 입력하면 파일에 남을 수 있습니다. `data/`는 공유하지 마세요.

토큰은 Codex가 보고한 스레드별 사용량을 합산합니다. 캐시 입력과 추론 토큰을 포함하는 총사용량이며 금액 또는 절약률이 아닙니다. 예산 중단은 사용량 이벤트 수신 시 처리되어 일부 초과할 수 있고, 이벤트가 없으면 사용량을 확정할 수 없습니다. 모델 가격을 임의로 환산하지 않습니다.

쓰기 작업이 포함된 배치는 순차 실행하고, 읽기 작업은 설정한 수만큼 병렬 실행합니다. 서로 다른 배치에서도 쓰기 작업은 다른 팀원 작업과 겹치지 않습니다. 같은 에이전트에게 작업을 중복 배정하지 않습니다. 메인 AI와 기본 조사·검증 담당은 읽기 전용입니다. 등록된 에이전트는 Codex의 별도 임시 스레드로 실행되며, 내부 재위임은 비활성화해 모니터링되지 않는 팀원이 생성되지 않게 합니다.

## 개발과 검증

```powershell
npm run check
npm test
node scripts/probe.mjs
```

`AGENT_DESK_PORT`(기본 4317), `AGENT_DESK_DATA`(기록 저장 폴더), `AGENT_DESK_CODEX`(Codex 실행 파일 경로)로 실행 환경을 바꿀 수 있습니다. 서버는 `127.0.0.1`에만 바인딩하고 같은 출처와 실행 시 생성한 요청 토큰을 확인합니다. 다른 PC나 모바일 접속은 이 버전의 범위에 포함하지 않습니다.

Codex app-server의 실험적 동적 도구 인터페이스를 사용합니다. CLI 업데이트 시 연결 검사가 필요할 수 있습니다. 이 PC에서 확인한 버전은 `codex-cli 0.162.0-alpha.17.2`, Node.js `v24.19.0`입니다.

공식 프로토콜: https://learn.chatgpt.com/docs/app-server
